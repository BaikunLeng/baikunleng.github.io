IMPLEMENTATION STATUS / V4

The work, not the claim.

A multi-domain prototype. Not a model leaderboard.

What runs today

Procurement, monthly data reconciliation and housing each have their own fictional world, parameters, tool effects, artifacts and output verifier. Two reference scripts actually execute in the browser.

What is still in design

Research, office coordination and travel have task specifications, but no executable environment yet. Free-text tasks are local drafts, not model-interpreted instructions.

What the checks mean

Outputs are checked against public fixture truth. These are deterministic functional tests, not measures of general intelligence or production reliability. No preferred answer or model score is hard-coded into a leaderboard.

What the trace contains

Calls and results recorded during the local run, with separate artifact and state records. These are not reconstructed private Gmail traces. Model usage is unavailable, not fabricated.

Verified evaluation will require server-side isolation, real model adapters, independent task review, private test data and calibrated graders. None are implied by this demo.
